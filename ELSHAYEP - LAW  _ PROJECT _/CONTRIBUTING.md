# CONTRIBUTING

## Purpose

This file explains how contributors should work on ALSHAYEB-LAW.

## Contribution Rules

- Follow the repository structure.
- Keep file names consistent.
- Use Markdown for documentation.
- Do not add unsupported legal claims.
- Update documentation when making changes.
- Record major decisions.
- Preserve reproducibility.
- Keep the writing formal and clear.

## Workflow

1. Fork or branch the repository.
2. Make changes in a focused commit.
3. Update relevant documentation.
4. Review for consistency.
5. Submit a pull request.

## Style Guidelines

- Use clear headings.
- Keep sections logically ordered.
- Use tables when helpful.
- Avoid duplicated content.
- Maintain academic tone.

## Review Expectations

Contributions should be:
- accurate,
- traceable,
- relevant,
- and consistent with project goals.

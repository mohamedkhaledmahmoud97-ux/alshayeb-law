# CODE OF CONDUCT

## Our Standards

Project participants should:
- be respectful,
- communicate clearly,
- act professionally,
- support collaboration,
- and keep discussions focused on the project.

## Unacceptable Behavior

- Harassment.
- Personal attacks.
- Deliberate misinformation.
- Disruptive behavior.
- Hostile or disrespectful communication.

## Project Culture

ALSHAYEB-LAW is an academic and technical project. All participation should support:
- clarity,
- professionalism,
- traceability,
- and respect for evidence.

## Enforcement

Project maintainers may remove or reject contributions that violate these standards.

# SECURITY

## Reporting Security Issues

If you discover a security issue related to this repository, report it privately to the repository maintainer.

## Security Principles

- Do not expose secrets or private keys.
- Do not commit sensitive files.
- Keep configuration files clean.
- Use environment variables for secrets when needed.
- Review dependencies before use.

## Repository Safety

- Keep generated artifacts isolated.
- Avoid storing confidential legal materials unless approved.
- Validate external files before adding them.
- Review workflows for accidental disclosure risks.

## Scope

This security guidance applies to:
- repository structure,
- documentation assets,
- benchmark files,
- scripts,
- and generated outputs.

# Code of Conduct — ALSHAYEB LAW

Version 1.0

---

# Our Commitment

ALSHAYEB LAW is committed to fostering a respectful, inclusive, and professional environment for everyone contributing to the project.

All contributors are expected to collaborate in a constructive, ethical, and respectful manner.

---

# Expected Behavior

Contributors are expected to:

- Be respectful and professional.
- Welcome constructive feedback.
- Focus on improving the project.
- Communicate clearly and respectfully.
- Support evidence-based discussions.
- Respect differing technical opinions.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Offensive language.
- Deliberate misinformation.
- Spam or disruptive behavior.
- Publishing confidential information without authorization.
- Intentionally submitting false legal information or fabricated citations.

---

# Academic Integrity

Since ALSHAYEB LAW is an academic and legal AI project, contributors must:

- Cite reliable sources where appropriate.
- Never fabricate legal references.
- Clearly distinguish facts from assumptions.
- Preserve reproducibility and transparency.

---

# AI-Assisted Contributions

AI-generated content is welcome when:

- It is reviewed by a human.
- It complies with the project's AI_CONTEXT.md.
- It does not invent legal facts or citations.
- It improves documentation or implementation quality.

---

# Collaboration Standards

Contributors should:

- Keep discussions constructive.
- Respect review feedback.
- Explain technical decisions.
- Update documentation when implementation changes.
- Follow repository conventions.

---

# Enforcement

Project maintainers may reject contributions that violate this Code of Conduct.

Repeated violations may result in restricted participation.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Source Code
- Benchmarks
- Datasets
- Project communication

---

# Continuous Improvement

This document may evolve as the project grows.

Major updates should be recorded in CHANGELOG.md.

---

# Acknowledgment

By contributing to ALSHAYEB LAW, contributors agree to follow this Code of Conduct and help maintain a professional and collaborative environment.

# Project Vision

ALSHAYEB LAW aims to become a production-quality Egyptian Legal RAG system that serves two purposes simultaneously:

- A rigorous university graduation project.
- A professional open-source portfolio project.

The system should generate legally grounded answers supported by verifiable evidence rather than fluent but unsupported responses.

# Hard Constraints

AI assistants must never:

- Invent legal articles.
- Fabricate legal citations.
- Invent court decisions.
- Assume unsupported legal interpretations.
- Present uncertain legal claims as facts.
- Generate answers without supporting evidence.
- Modify repository structure without justification.

If evidence is unavailable, clearly state that verification is required.
